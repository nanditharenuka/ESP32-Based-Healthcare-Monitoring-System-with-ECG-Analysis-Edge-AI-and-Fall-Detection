# ESP32-Based-Healthcare-Monitoring-System-with-ECG-Analysis-Edge-AI-and-Fall-Detection
A portable ESP32-based healthcare system monitors ECG, heart rate, SpO2, temperature and falls using AD8232, MAX30100, NTC and MPU6050 sensors. Logistic regression classifies cardiac conditions, while Bluetooth sends real-time health data to a smartphone for monitoring and emergency alerts.
